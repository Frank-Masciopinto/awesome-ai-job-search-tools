# Contributing

Thanks for helping keep this list useful. Before opening a pull request, please check the following.

## Guidelines

- The resource should be genuinely useful for job seekers, not a tangential or unrelated tool.
- Free or freemium tools are preferred. Fully paid tools with no free tier need a strong reason for inclusion.
- One resource per pull request. This keeps review fast and history clean.
- Add your entry in alphabetical order within its category.
- Write a single, factual, one line description. No marketing language, no superlatives, no exclamation marks.
- Do not add a resource you are affiliated with unless you disclose the affiliation in the pull request description.
- Broken links or discontinued products will be removed. Feel free to open a pull request for that too.

## Format

```markdown
- [Name](https://example.com) - What it does, in plain language, under 20 words.
```

## New categories

If a resource does not fit an existing category and you believe a new category is warranted, open an issue first to discuss it before submitting the pull request.

## Review

Pull requests are typically reviewed within a few days. If a submission is declined, it is usually because the resource is too niche, no longer maintained, or reads as purely promotional.
